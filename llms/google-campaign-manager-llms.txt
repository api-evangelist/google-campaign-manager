# Google Campaign Manager 360

> Campaign Manager 360 is Google's ad-serving, trafficking and measurement platform for advertisers and agencies. The Campaign Manager 360 API (service name `dfareporting`) lets you programmatically manage advertisers, campaigns, ads, creatives, placements, floodlight activities, remarketing lists and reporting.

Generated by API Evangelist on 2026-08-13 from the provider's own developer documentation and the Google Discovery Document for `dfareporting:v5` (revision 20260721). Google does not publish an `llms.txt` for this API — `https://developers.google.com/llms.txt` returns HTTP 404.

## Version status — read this first

- **Current version: v5.** Base URL `https://dfareporting.googleapis.com/dfareporting/v5/`. Preferred in Google's Discovery directory. No deprecation or sunset date announced.
- **v4 is gone.** `https://dfareporting.googleapis.com/dfareporting/v4/userprofiles` returns HTTP 404 and the Discovery document for v4 is no longer served. Any code, SDK pin or spec targeting v4 is calling a retired API.
- **v3.5** still answers Discovery but is not preferred.
- Google supports roughly three concurrent versions and gives about seven months between a deprecation announcement and sunset. Sunset versions return HTTP 403 first, then HTTP 404 once fully deactivated.
- The OpenAPI documents in this repository describe **v4** and are retained as a historical record of that surface. Treat `discovery/google-campaign-manager-dfareporting-v5-discovery.json` as the authoritative current contract.

## Base URLs

- REST API: `https://dfareporting.googleapis.com/dfareporting/v5/`
- Discovery Document: `https://dfareporting.googleapis.com/$discovery/rest?version=v5`
- Discovery directory: `https://discovery.googleapis.com/discovery/v1/apis?name=dfareporting`

## Authentication

- OAuth 2.0 authorization code flow, or a service account with domain-wide delegation.
- Authorization endpoint: `https://accounts.google.com/o/oauth2/v2/auth`
- Token endpoint: `https://oauth2.googleapis.com/token`
- Scopes:
  - `https://www.googleapis.com/auth/dfatrafficking` — view and manage display ad campaigns
  - `https://www.googleapis.com/auth/dfareporting` — view and manage reports
  - `https://www.googleapis.com/auth/ddmconversions` — manage DoubleClick Digital Marketing conversions
- There is no API-key path to user data. Every call also needs a Campaign Manager 360 **user profile ID**; almost every path begins `/userprofiles/{profileId}/`.
- Docs: https://developers.google.com/doubleclick-advertisers/authorizing and https://developers.google.com/doubleclick-advertisers/service_accounts

## Quotas and rate limits

- 50,000 requests per project per day, refreshing at midnight PST. Increasable.
- 1 query per second per project by default (shown in the Google API Console as 60 queries per minute per user); maximum 600 per minute (10 QPS).
- Exhaustion returns **HTTP 403**, not 429, with reason `dailyLimitExceeded`, `userRateLimitExceeded` or `quotaExceeded`.
- No `RateLimit-*` or `Retry-After` headers are documented. Use exponential backoff.
- Google advises against concurrent write requests and against exceeding 10 QPS.
- Docs: https://developers.google.com/doubleclick-advertisers/quotas

## Conventions

- Paging: `maxResults` + `pageToken` on list methods; responses carry `nextPageToken`.
- Partial response: the `fields` query parameter selects a subset of the response (`fields=items(id,name)`).
- Compression: send `Accept-Encoding: gzip` and include `gzip` in the User-Agent string.
- Errors: Google JSON error envelope — `error.code`, `error.message`, `error.status`, `error.errors[].reason`. Not RFC 9457 `application/problem+json`.
- No idempotency-key header is documented. `PUT` (update) is naturally idempotent; `POST` (insert) is not.

## Agent surfaces

- No Model Context Protocol server is published by Google for Campaign Manager 360.
- No A2A agent card is served on any Campaign Manager host.
- Nothing is served under `/.well-known/` on `dfareporting.googleapis.com`.
- The machine-readable contract an agent should read is the Google Discovery Document.
